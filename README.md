# KOSEN Question Bank

高専入試の過去問分析・出題傾向整理・オリジナル演習問題を管理するためのデータリポジトリです。

## 方針

- 過去問は分析・出典管理の対象とし、問題文・図版の無断転載を前提にしない。
- 演習用コンテンツは、過去問の設定・数値・条件・図を単純に置き換えただけの問題ではなく、独立したオリジナル問題として制作する。
- 正答には検証状態と根拠を記録する。公式解答と独自解答を明確に区別する。
- 未確認・曖昧な箇所を推測で埋めず、`unresolved` として残す。
- すべての問題に一意なIDを付与し、出典・改訂履歴を追跡可能にする。

## 対象

- 数学
- 理科
- 社会
- 英語・国語（資料が揃い次第追加）

## ディレクトリ

```text
data/
  questions/       # オリジナル演習問題（科目別JSON）
  past-exams/      # 過去問のメタデータ・設問台帳（本文転載はしない）
  analysis/        # 年度別・科目別の分析データ
  schemas/         # JSON Schema
docs/
  methodology/     # 分析・問題制作・検証ルール
  reports/         # 監査・進捗レポート
scripts/           # データ検証スクリプト
```

## データの状態

この初期コミットでは、データ形式と運用ルールを定義しています。実際の問題・分析データは、原本と照合して検証したものだけを追加します。

## 検証

`python scripts/validate_questions.py` で問題データの基本構造を検査できます。

## ライセンス・権利

このリポジトリのオリジナル文章・解説・構造化データの利用条件は、別途明示するまで権利放棄を意味しません。第三者の過去問本文・図版・解答解説は、利用許諾や公開条件を確認せずに転載しないでください。
