# Question Bank

入試・学習向けの問題データ、出題傾向の分析、オリジナル演習問題を管理するデータリポジトリです。

## 方針

- 過去問は分析・出典管理の対象とし、許諾等を確認できない問題文・図版を公開用データへ転載しない。
- 演習問題は、過去問の数値や設定を置き換えただけではない独立したオリジナル問題として制作する。
- 公式解答と独立計算を区別し、未確認の解答は推測で埋めず `unresolved` として残す。
- 問題ごとに一意なID・出典・検証状態を記録する。

## 対象科目

- 数学
- 理科
- 社会
- 英語・国語（資料・問題の追加待ち）

## データ構成

```text
data/
  questions/       # オリジナル演習問題（科目別JSON）
  past-exams/      # 過去問のメタデータ・設問台帳
  analysis/        # 年度別・科目別の分析データ
  schemas/         # JSON Schema
docs/
  analysis/        # 科目別の分析レポート
  methodology/     # 分析・問題制作・検証ルール
  policies/        # データ品質・権利管理方針
  reports/         # 監査・進捗レポート
scripts/           # データ検証スクリプト
```

## 更新履歴・開発ログ

変更内容とデータベース整備の記録は [docs/RELEASE_NOTES.md](docs/RELEASE_NOTES.md) にまとめています。ここはWebサイトではなく問題データのリポジトリのため、サイト内ポップアップではなくGitHub上の開発ログとして管理します。 初回の問題監査結果は [2026-11-05問題データ初回監査レポート](docs/reports/2026-11-05-question-audit.md) を参照してください。

## 検証

`python scripts/validate_questions.py` で問題データの基本構造・ID重複・検証状態を確認できます。この検証は構造検査であり、問題の正答や解説の正しさを保証するものではありません。

## ライセンス・権利

このリポジトリのオリジナル文章・解説・構造化データは、別途明示するまで権利放棄を意味しません。第三者の過去問本文・図版・解答解説は、利用許諾や別の適法な利用根拠を確認せずに公開・配布しないでください。公開リポジトリに置かれたファイルは第三者が閲覧・取得できるため、公開前に必ず権利と公開条件を確認してください。
