# データ品質・権利管理方針

## 過去問資料

- 過去問本文・図版の利用は、著作権法上の私的使用に該当する場合など、適法な根拠がある範囲に限る。閲覧者を限定していることや非営利であることだけで、私的使用に該当するとは判断しない。
- GitHubへの公開、一般向けウェブサイトへの掲載、第三者への配布・共有では、権利者の許諾または別の適法な利用根拠を事前に確認する。確認できない本文・図版は公開用データに収録しない。
- このリポジトリは現在Publicであり、GitHub上のファイルは第三者が閲覧・取得できる。リポジトリ内の `kosen_*_past_papers/` に過去問PDFが存在するが、リポジトリに置かれている事実は公開・再配布の許諾を意味しない。各PDFの公開条件を確認し、確認できない場合は公開状態のままにしない。
- 過去問を分析・参照した場合は、年度・科目・大問・小問など出典情報を記録し、原文転載と独自作成問題を明確に区別する。

## 解答・問題品質

- 公式正解表による確認と独立計算を明確に区別する。
- 未確定の解答は `unresolved` とし推測で埋めない。
- オリジナル問題は設定・数値・条件・図・問い方を独立に設計し、単純な数値置換や選択式への変換を避ける。
- 正答・解説・選択肢を独立検証し、検証状態を記録する。
- `review` は確認中であり、公開品質の確定を意味しない。`verified` への変更は、問題文・正答・解説・選択肢・出典・権利面の確認が終わった個別問題に限る。
