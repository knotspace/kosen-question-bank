# データ品質・権利管理方針

- 過去問本文・図版の転記は、著作権法上の私的使用の範囲内に限り、例外的に可とする。私的使用に当たるかは利用の実態で判断し、閲覧者を限定していることや非営利であることだけを根拠にしない。
- GitHubへの公開、一般向けウェブサイトへの掲載、第三者への配布・共有など、私的使用の範囲を超える利用では、権利者の許諾または別の適法な利用根拠を事前に確認する。許諾等を確認できない本文・図版は公開用データに収録しない。
- 過去問を分析・参照した場合は、年度・科目・大問・小問など出典情報を記録し、原文転載と独自作成問題を明確に区別する。
- 公式正解表による確認と独立計算を明確に区別する。
- 未確定の解答は `unresolved` とし推測で埋めない。
- オリジナル問題は設定・数値・条件・図・問い方を独立に設計し、単純な数値置換や選択式への変換を避ける。
- 正答・解説・選択肢を独立検証し、検証状態を記録する。
