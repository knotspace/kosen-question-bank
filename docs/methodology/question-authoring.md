# オリジナル問題の制作・検証手順

1. 対象学年・科目・単元・到達目標を定義する。
2. 出題傾向を抽象化して記録する（例：複数条件の整理、実験結果の読み取り）。
3. 過去問の具体的な設定や数値を流用せず、新しい題材・条件・問いを設計する。
4. 正答を作成し、途中式・根拠・採点基準を明記する。
5. 別解または独立した再計算で正答を検証する。
6. 選択肢問題は全選択肢の正誤と、誤答になる理由を確認する。
7. 条件不足・複数正答・表記揺れ・単位・図表との不整合を確認する。
8. メタデータと参考にした出題の出典IDを登録する。
9. スキーマ検証とレビューを通過してから `verified` にする。

## 公開判定

- `draft`: 制作中
- `review`: 内容レビュー中
- `verified`: 解答・条件・表現の検証済み
- `retired`: 誤りや古さにより公開停止

`draft` と `review` は本番の演習画面に出さない。
