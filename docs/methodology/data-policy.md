# データ運用・権利ポリシー

## 1. 過去問の記録

過去問について保存する基本情報は、年度、科目、大問・小問番号、分野、出題形式、配点（確認できた場合）、出典、確認状態とする。設問本文・図版・公式解答の丸ごとの転載は行わない。

## 2. オリジナル問題

過去問を参考にする場合でも、次の要素を独立して設計する。

- 問題設定・題材
- 条件・数値・図表
- 問い方・誘導・選択肢
- 解法と解説

単なる数値変更、選択式への変換、文章の言い換えだけを「オリジナル」と扱わない。参考にした過去問はメタデータで示す。

## 3. 正答の検証状態

- `official`: 公開された公式正解と照合済み
- `independently_verified`: 独立に解き、別経路または再計算で検証済み
- `provisional`: 暫定。公開用の確定問題として扱わない
- `unresolved`: 条件不足・複数解釈などで確定できない

公式解答が存在しない年度・科目について、独自解答を公式解答と表現しない。

## 4. 不確実性

曖昧な条件、複数の解釈、資料の欠落、判読不能箇所は記録し、推測で補完しない。未解決の問題は演習公開対象から除外する。

## 5. 重複管理

代替ファイルや別名PDFは、ファイル名だけで同一と判断しない。ページ数・内容・ハッシュ等を比較して重複を記録する。
