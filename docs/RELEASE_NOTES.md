# KOSEN Question Bank — 更新履歴

## 2026-11-05 v0.3.0
- 数学3問・理科3問・社会3問のオリジナル演習を追加（計9問）
- 追加データを既存の検証スクリプトの対象に含めた
- 追加問題はすべて `review` とし、公開確定扱いにしない
- 二次方程式の面積問題について、答えと解説の一致を修正

## 2026-11-04 v0.2.0
- 数学・理科・社会のオリジナル演習問題と、年度別過去問分析・設問台帳を分けて管理
- 問題ごとの一意なID、出典情報、検証状態を追跡できる構成を整備
- 公式解答の確認状況と独立計算による検証状況を区別
- 未確認の解答を推測で確定せず、未解決として保持する運用を明記
- データベース監査レポートへの導線をREADMEに追加

## 開発ログの書き方
新しい変更は先頭に日付・バージョンを追加し、次の分類で記録します。

- **データ追加**：新しい問題、年度、設問台帳、分析資料
- **品質改善**：解説・正答・出典・スキーマの検証
- **不具合修正**：ID重複、形式不備、参照切れなど
- **開発基盤**：検証スクリプト、データ構造、ドキュメント

問題データの追加時は、登録数だけでなく検証状態も併記してください。
