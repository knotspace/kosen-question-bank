## 開発ログの書き方
新しい変更は先頭に日付・バージョンを追加し、次の分類で記録します。

- **データ追加**：新しい問題、年度、設問台帳、分析資料
- **品質改善**：解説・正答・出典・スキーマの検証
- **不具合修正**：ID重複、形式不備、参照切れなど
- **開発基盤**：検証スクリプト、データ構造、ドキュメント

問題データの追加時は、登録数だけでなく検証状態も併記してください。
